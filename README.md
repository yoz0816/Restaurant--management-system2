# 🍽️ Restaurant Management System (RMS)

A desktop-based **Restaurant Management System** built using **C++ and Qt**.  
It manages restaurant operations such as menu handling, order processing, billing, and sales reporting.

## 📌 Overview

The system provides a complete solution for restaurant operations including:

- Authentication system
- Menu management (CRUD operations)
- Order processing system
- Billing with tax calculation
- Sales reporting

---

## 🚀 Features

### 🔐 Authentication
- Login system
- Registration system
- Role-based access (Admin / Cashier)

---

### 👨‍💼 Admin Dashboard
- Add menu items  
- Update menu items  
- Delete menu items  
- Sorting algorithms:
  - Bubble Sort  
  - Selection Sort  
- Searching:
  - Linear Search  
- View sales report  

---

### 🧾 User Dashboard
- View menu  
- Search menu items  
- Add items to order  
- Remove items from order  
- Generate bill with tax  
- Auto stock update  
- Auto sales tracking

## ⚙️ Installation Guide

### 🪟 Windows

1. Install Qt from https://www.qt.io/download  
2. Open Qt Creator  
3. Open project:

RMS.pro

4. Select Kit (MinGW recommended)  
5. Click Run ▶

## 🔄 System Flow

1. User logs in  
2. System validates credentials  
3. Redirect based on role:
   - Admin → Admin Dashboard  
   - User → User Dashboard  
4. Admin manages menu  
5. User places order  
6. Bill is generated  
7. Database is updated:
   - `orders` table  
   - `order_items` table  
8. Stock and sales are updated automatically
